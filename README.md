# iRede — Backend (Certificados & iRede.c)

API e serviços do sistema de emissão de **certificados de participação** dos
Residentes e Alunos do iRede, com registro na blockchain **Polygon** e
integração à moeda utilitária **Utility iRede Coin (iRede.c)**.

Este repositório é um **submódulo** do projeto principal
[carlosdelfino/irede_web3_moeda_certificado](https://github.com/carlosdelfino/irede_web3_moeda_certificado).

## Escopo do módulo

- Emissão, validação e consulta de certificados de participação.
- Integração com a blockchain Polygon para registro/ancoragem dos certificados.
- Regras de distribuição do token utilitário iRede.c por etapa, desafios e emissões.
- Autenticação e autorização de participantes e administradores.

## Estado atual
